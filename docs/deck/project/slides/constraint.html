FIRST WAY · THE CONSTRAINT

Every system has one bottleneck

An hour saved at the bottleneck is an hour saved for the whole system. An hour saved anywhere else is an illusion.

Identify

Exploit

Subordinate

Elevate

Repeat: it moves

After Eliyahu Goldratt, The Goal (1984)

Theory of Constraints. Every pipeline has one stage that limits the whole thing. Adding capacity anywhere else feels productive and changes nothing you can measure. The five focusing steps: find the constraint, get the most out of it, make everything else serve it, then add capacity there, and then go looking again, because once you relieve it the bottleneck moves somewhere else. In the game the board names the bottleneck for you, but only after day 10, because a line that's still filling up has a bottleneck that wanders. Tell people to watch for it, and don't say which station it is.
