CASE · MARCH 2026 · AMAZON RETAIL

A code safety reset

  • A run of retail site outages in early March was linked, in internal documents, to AI-assisted code changes.
  • The response: a 90-day code safety reset for critical systems.
  • And senior engineers must now sign off on AI-assisted changes from junior and mid-level engineers.

THE PATTERN

At one of the most automated companies there is, the answer to agent-scale change was more senior attention, spent at review.

TechRadar and Fortune, March 2026, reporting an internal Amazon email

Early March 2026, Amazon's retail site had a series of outages. Internal documents reportedly connected them to AI-assisted changes. Dave Treadwell, the SVP of e-commerce services, wrote internally that site availability "has not been good recently", and the fix included requiring senior engineers to sign off on AI-assisted changes from junior and mid-level engineers, plus a 90-day code safety reset for critical systems. Secondary reporting puts a large number on lost orders for one incident. I haven't verified it against primary reporting, so I'm leaving it out. [Verify before quoting any figure.] This is the third company in a row where the fix put human attention back into the loop, at the planning end or the review end.
