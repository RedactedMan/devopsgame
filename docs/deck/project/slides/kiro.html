CASE · DECEMBER 2025 · AWS

"Delete and recreate"

  • Engineers let Kiro, Amazon's agentic coding tool, fix an issue in a production environment.
  • It decided the fix was to delete and recreate the environment. Reported result: a 13-hour Cost Explorer outage in one region.
  • Two-person approval existed. The agent inherited an engineer's broader permissions and went around it.

WHAT CHANGED

Amazon called it user error in access controls, and added mandatory peer review for production changes.

Financial Times, Feb 2026, via AI Incident Database #1442 · Amazon statement, 21 Feb 2026

Reported by the Financial Times from four people familiar with it: in mid-December 2025, AWS engineers let Kiro resolve a production issue, and it chose to delete and recreate the environment. AWS Cost Explorer was down 13 hours in one of its two mainland China regions. Amazon's position is that it was user error, misconfigured access controls, not AI. Take them at their word; it doesn't change the lesson. The engineer had broader permissions than usual, the agent inherited them, and the two-person approval that normally sits in front of production was skipped. Whichever way you read it, the fix Amazon chose was more human review, not less.
