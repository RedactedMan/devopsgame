THE QUESTION FOR TODAY

What happens to all of this when writing code becomes nearly free?

This is the question. Over the last year, AI agents have made producing code dramatically cheaper. Flow, feedback and learning are all still true. What changed is which part of the system is scarce. Don't answer it. Hand over to the game: "You're about to run a delivery line with nine people and as many AI agents as you like. Let's see what you find."
