CORE PRINCIPLES

The Three Ways

1

Flow

Work moves left to right, fast, in small batches, with nothing piling up in between.

2

Feedback

Problems travel right to left, fast, so they're fixed at the source instead of downstream.

3

Continual learning

Improving the system is part of the work: experiment, learn from failure, share it.

Kim, Humble, Debois, Willis: The DevOps Handbook

DevOps has a lot of definitions. The one I find most useful is the Three Ways from The DevOps Handbook, because each one is a direction work or information travels. The First Way is about the flow of work from idea to production. The Second is about information flowing back the other way. The Third is about getting better at both over time. About ten minutes on these, then the game. The game is built on the Three Ways: its planned campaign follows them, and the part you'll play today is mostly the First Way.
