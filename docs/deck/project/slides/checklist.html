FOR MONDAY

Three things to take back

1

Budget attention like capacity

Cap agent work in flight at what your reviewers can actually read. Count review hours, not agent seats.

2

Put people at plan and review

Written intent before work starts, and a person who owns every merge. No agent-only path to production.

3

Measure true quality

Track change failure rate, rework and escaped defects. PR counts and approvals are too easy to satisfy.

If you remember three things: 1. Treat human attention as a capacity with a number on it. Work out how many agent-produced changes your reviewers can genuinely read in a week, and set agent WIP limits from that. In the game, the fix for idle agents wasn't more agents; it was a person at Review. 2. Humans at both ends. A written intent before any agent starts, and a named human who owns every merge. Make "no agent-only path to production" an enforced control, not a sentence in a prompt. Replit and AWS both learned that one. 3. Measure outcomes. The DORA stability metrics, rework rate, escaped defects. If your dashboard went up when agents arrived, check whether the thing it measures got better or just got cheaper to satisfy.
