SECOND WAY · FEEDBACK

Find problems while they're cheap

Fast CI

A slow suite makes every failure cost more, because the code keeps moving while you wait.

Stop the line

When defects show up, fix the source before shipping more of them.

Telemetry

Most of the time to restore service is the time to notice it's broken.

The Second Way is feedback. The earlier you find a problem, the cheaper it is to fix, and the more likely you fix the cause rather than the symptom. Three practices: tests fast enough that people wait for them, the authority to stop the line when something's wrong, and telemetry good enough that production tells you before customers do. Park this idea for the debrief. Code review is a feedback loop too, and it's the one that agents stress hardest.
