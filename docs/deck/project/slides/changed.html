THE LAST YEAR

Four changes since agents joined the loop

1 · Planning is a bottleneck

Agents amplify a vague spec. Intent has to be written down before anyone, or anything, starts.

2 · Review is the constraint

Producing a change got cheap. Reading one carefully didn't.

3 · WIP explodes

Ten parallel agent branches is one click. Drift and conflicts grow faster than the branch count.

4 · Agent review rubber-stamps

It catches mechanical defects and misses design ones. The dashboard looks great.

Four process changes I've seen over the last year. Each one maps back to a principle from the first ten minutes. 1. Planning: an agent does exactly what you asked, fast and at scale. If the spec is vague, you get a lot of confidently wrong code. Time spent on intent up front got more valuable, not less. 2. Review is the Theory of Constraints slide, live. The bottleneck moved from writing to reading. 3. WIP is Little's Law. Starting work costs nothing now, so teams start far too much of it. 4. Agent review is the Second Way under stress, and it's Goodhart's Law: once a metric can be satisfied cheaply, it will be.
