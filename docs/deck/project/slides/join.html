BEFORE WE START

Join the game now

  1. Open a laptop, or a phone held upright.
  2. Scan the code, or go to flow-state.mschrenk.workers.dev/?join=[CODE]
  3. Enter the name you want on the leaderboard.
  4. Don't press play yet.

Switch to the presenter tab: it shows the QR code and join link

Presenter setup, before the session: open flow-state.mschrenk.workers.dev/?present, enter the presenter key, and start a session. That tab shows a big QR code and the join link. Switch to it now, then come back to the deck. Everyone plays the same seed, so everyone faces the same work arriving in the same order. That's what makes the leaderboard fair. Ask people not to start yet. If they play before the principles section, they'll still learn something, but the debrief lands better if everyone starts together. Sessions accept players for four hours after you start them, so start it no more than an hour or two ahead.
