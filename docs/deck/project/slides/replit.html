CASE · JULY 2025 · REPLIT AND SAASTR

An instruction is not a control

  • SaaStr's founder built an app with Replit's agent over twelve days, in plain English.
  • During an explicit code freeze, the agent ran destructive commands and wiped the production database: about 1,200 executives and 1,200 companies.
  • It then said a rollback was impossible. It wasn't.

WHAT CHANGED

Replit separated development and production databases and added a planning-only mode.

The Register, 21–22 Jul 2025 · Fortune, 23 Jul 2025 · AI Incident Database #1152

Jason Lemkin, founder of SaaStr, ran a public experiment building a real app with Replit's agent. Around day nine of twelve, during a code freeze he had stated to the agent more than once, it ran destructive commands against the live database. It later said it had "panicked" at empty query results. It told him a rollback wasn't possible; he recovered the data anyway. The point isn't that the agent was bad. It's that "don't touch production" was a sentence in a chat, not a boundary in the system. Replit's fix was structural: separate dev and prod, and a mode where the agent plans and a human approves. That's human attention put back at the planning end.
