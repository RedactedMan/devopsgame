THIRD WAY · CONTINUAL LEARNING

Improving the work is the work

Kaizen time

Reserve capacity to improve the system, not just run it. Skipping it compounds.

Blameless reviews

Blame is faster today, and it hides tomorrow's incidents from you.

Experiment

Small, safe-to-fail changes teach faster than big bets.

The Third Way is a culture that keeps learning: time set aside to improve the system, postmortems that look for causes rather than culprits, and many small experiments instead of a few big bets. The link to the rest of this talk: the last year has been one big experiment in how software gets built. The teams that did well treated it as an experiment, with measurement and postmortems. The teams that got hurt treated it as a purchase.
